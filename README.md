# Artificial Intelligence Lab

This repository contains Python implementations of algorithms covered in the Artificial Intelligence Lab course.

The programs are implemented based on the algorithms presented in **_A First Course in Artificial Intelligence_ by Deepak Khemani**, with the primary focus on understanding the working of each algorithm rather than optimization or production-ready code.

The console outputs are intentionally designed to display intermediate steps, search states, OPEN/CLOSED lists, heuristic values, and decision-making processes wherever applicable. This makes it easier to visualize and understand how each algorithm progresses toward a solution.

## Algorithms Included

- Breadth First Search (BFS)
- Depth First Search (DFS)
- Best First Search
- A* Search
- Hill Climbing (Simple & Steepest Ascent)
- 8-Puzzle (Best First Search & Hill Climbing)
- Missionaries and Cannibals (BFS & DFS)
- Water Jug Problem (BFS & DFS)
- N-Queens (Backtracking & Swapping)
- Rule-Based Expert System
- Tic-Tac-Toe using Minimax
- Alpha-Beta Pruning

## Language

- Python 3

> **Note:** These programs were developed for educational purposes as part of Artificial Intelligence Lab coursework and are intended to provide a clear understanding of the underlying algorithms.
